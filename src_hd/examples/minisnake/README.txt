MINISNAKE
by Fabrizio Caruso
Written with Cross-Lib for 200+ systems
https://github.com/Fabrizio-Caruso/CROSS-LIB

This is a Nokia Snake-inspired mini-game with 9 different modes:

1. classic       : similar to the first Nokia Snake
2. frenzy        : same as classic but with multiple apples that are spawned very quickly
3. insane        : similar to frenzy, with deadly inner blocks

4. classic wrap  : same as 1 but with no outer walls
5. frenzy wrap   : same as 2 but with no outer walls
6. insane wrap   : same as 3 above but with no outer walls

7. deluxe easy   : similar to 6 but with special items, few inner walls
8. deluxe medium : similar to 6 but with special items, more inner walls
9. deluxe hard   : similar to 6 but with special items, max inner walls

The game keeps track of records for all game modes.

If the snake does not eat for too long, it starts feeling hungry, gets angry and becomes must faster. 
If it does not get food quickly after becoming angry, it dies of starvation.
