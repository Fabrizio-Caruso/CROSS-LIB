Here are three example level files for the level-file loader.

These examples assume a `160 x 160` screen, matching the original game code. Save each as a plain text file, for example:

- `level1.txt`
- `level2.txt`
- `level3.txt`

Then select one by changing:

```c
#define LEVEL_FILE "level1.txt"
```

No `END` line is required.

---

## `level1.txt`

```text
; Level 1: simple three-platform climb

; Platforms
PLATFORM 0 159 160
PLATFORM 20 120 120
PLATFORM 60 80 60

; Stairs / elevators
STAIRS 48 120 159
STAIRS 88 80 120

; Enemies
ENEMY 30 118
ENEMY 70 78

; Items
ITEM 20 158
ITEM 30 119
SPECIAL 70 79
ITEM 100 79

; Player start
PLAYER 78 157
```
